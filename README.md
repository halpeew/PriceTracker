# PriceTracker

## Features
- Show all skins in your Steam inventory
- Display current market prices for each skin
- Calculate net price after Steam commission
- Indicate whether each item is tradeable (Yes/No)
- Third-party purchase analysis: enter price you will pay  or already paid on 3rd-party site to buy the selected item and compare with current price to see profit/loss in the terms of dollars and percentage
- Show current selling prices of your items on third-party sites and decide to what will your next move be.

## Usage 
1. **First-time setup** (run once):
```bash

run "login_setup.py"
```
that will redirect you to log-in your steam account. 


2. launch ```bash"JUITEST.py" ``` either using terminal or the code editor you have.
